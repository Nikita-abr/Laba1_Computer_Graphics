# Отчёт по лабораторной работе №1
**Тема: Цветовые модели RGB, CMYK, HSV**

Пиложение разработано на C++ с использованием Qt. Программа позволяет выбирать цвет из палитры, изменять его с помощью полей ввода и ползунков, а также отображать его компоненты в моделях RGB, CMYK и HSV с изменением всех других компонент в реальном времени.

Основная функция программы — `setRGB()`. Она принимает значения R, G и B, рассчитывает соответствующие компоненты CMYK и HSV, обновляет поля ввода, ползунки и цветовой предпросмотр.

Остальные функции зависят от `setRGB()`: `fromCMYK()` и `fromHSV()` переводят введённые значения в RGB, после чего вызывают `setRGB()` для обновления всех представлений цвета. Изменения через поля ввода и ползунки обрабатываются с помощью сигналов и слотов Qt.

В результате получено приложение, позволяющее интерактивно изменять цвет и автоматически пересчитывать его компоненты во всех трёх цветовых моделях.
